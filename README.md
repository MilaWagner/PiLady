# Канал «Источник» — как делать следующее видео (актуально на 05.11.2026)

Эта инструкция важнее старого документа «Instrukzia» (там устаревший процесс: Higgsfield, четверг 19:00, PDF).
Людмила Вагнер, YouTube-канал «Источник» (UC4z6uOVw8PK7Jrwh732TdOA). Она говорит голосом, по-русски, коротко.
Правила общения: короткие ответы, только текст-вопросы (без виджетов выбора), ничего не выдумывать (лучше спросить),
НЕ присылать PDF и длинные описания (она их не читает). Присылать только то, что нужно от неё (текст обложки одной строкой).

## Распорядок
- Видео каждые 2 дня в 00:00 по Берлину. Последнее запланированное: 28.11 (Миф о 10% мозга). Следующее: 30.11, потом 02.12 и т.д.
- Продолжать без команды: сделал, загрузил, запланировал, сразу следующее. Закончились темы: искать новые по трендам.
- Уже сделаны темы (не повторять): Старая душа, Женщина с остановленным сердцем, Последние 24 часа, Симуляция, Закон притяжения,
  Эффект наблюдателя, Синхроничность, Дежавю, Плацебо, Астрология, Медитация и мозг, Эффект Моцарта, Миф о 10% мозга, Душа выбирает родителей.
- Идеи: нейропластичность, магическое мышление, поза силы, миф о левом/правом полушарии, миф о стилях обучения.
  Все факты проверять по источникам, в скрипт добавлять только проверяемое (Людмила требует «без выдумок»).
- Обложку делает Людмила сама. Ей нужен только текст обложки (2–4 слова). Она присылает картинку, я ставлю на видео.

## Правила видео
Бесплатные клипы Coverr, меняются по смыслу, ни один клип не повторяется на всём канале (used_all.txt), первый кадр стоковый,
логотип слева внизу полупрозрачный и пульсирует, музыка очень тихая, правильные ударения в русском, светлые тёплые картинки (не тёмные),
названия и описания по-русски. Голос ru-RU-DmitryNeural (edge-tts). Последний блок = аутро с плашкой «ИСТОЧНИК».

## Файлы в этой ветке (скопировать в /home/claude/vbrain, пути в search.py и dl.py заданы туда)
script.py (BLOCKS, TITLE, COVER), tts.py, build_audio.py (seed и аккорды менять под каждое видео), clips.py (CLIPS по блокам),
render2.py, pdfgen.py (использовать ТОЛЬКО для meta.json: заголовок, описание с главами, теги; PDF не создавать и не слать),
search.py / cand_lists.py / dl.py (поиск и скачивание клипов), avatar.jpg (логотип), used_all.txt (использованные клипы).
Нужны: ffmpeg, python-пакеты edge-tts, numpy, opencv-python, pillow, reportlab; шрифты Lora и DejaVu (как в render2.py/pdfgen.py).

## Процесс видео (каждое в своей папке /home/claude/vbrain-<имя>, скопировать туда скрипты)
1. script.py: блоки текста (~6–7 мин, ~10 блоков), TITLE, COVER. Факты проверить поиском.
2. tts.py (нужна папка tts/, долго идёт, ждать окончания процесса), потом build_audio.py (даёт timeline.json, audio.m4a, voice.npy).
3. Клипы: `python3 search.py "запрос 1" "запрос 2"` (фильтрует использованные), дописать кандидатов в cand_lists.py, скачать dl.py
   (ВНИМАНИЕ: dl.py пропускает slugs из used_all.txt и перезаписывает clips/durs.txt, поэтому запускать один раз для нового набора).
   Валидный клип: длина ≥4.8 с и слот ≤1.2*(клип−0.6). Заполнить clips.py. Новые slug дописать в used_all.txt (без пустых строк).
4. `python3 render2.py prep`, затем две половины через setsid nohup (NF=ceil(total*24), H=int(NF*6/10)): `render2.py 0 H c0.mp4`, `render2.py H NF c1.mp4`.
   Склейка: `ffmpeg -f concat -i l.txt -i audio.m4a -c copy -shortest out-1080p.mp4`. Превью 720p для чата (<30 МБ).
5. pdfgen.py → meta.json (только это использовать).
6. Превью 720p в чат Людмиле и сразу загрузка (она не ждёт подтверждения, если не просила).

## Загрузка в YouTube Studio (без файла на диске; встроенный браузер, доступ studio.youtube.com через request_access)
- Файл 1080p порезать на части по 12 МБ в папку upN, закоммитить в временную ветку репозитория MilaWagner/PiLady (git clone есть
  в /home/claude/pilady, если нет: add_repo + clone), `timeout 450 git push -q origin <ветка>`.
- Открыть https://studio.youtube.com/channel/UC4z6uOVw8PK7Jrwh732TdOA/videos/upload?d=ud, JS: собрать части с
  raw.githubusercontent.com/MilaWagner/PiLady/<ветка>/upN/<имя>.partNN в window.__p, проверить общий размер,
  `new File(window.__p,name,{type:'video/mp4'})` через DataTransfer в input[name=Filedata] + событие change. JS заканчивать выражением (без return).
- Ждать ~25–30 с. Заполнить `ytcp-uploads-dialog #textbox` ×2 (заголовок, описание, execCommand). Клики: VIDEO_MADE_FOR_KIDS_NOT_MFK,
  #toggle-button, VIDEO_HAS_ALTERED_CONTENT_YES, VIDEO_PAID_PRODUCT_PLACEMENT_NO. Теги только свои (удалить теги канала по умолчанию:
  источник, бог, кто я, предназначение). Без Премьеры.
- Дождаться конца загрузки, #next-button ×3, #second-container-expand-button, #datepicker-trigger (нужен скриншот календаря),
  выбрать день (иногда нужен второй клик), `#done-button`, закрыть «We're still checking your content», проверить «Video scheduled»
  и в списке видео статус Scheduled.
- Обложка: https://studio.youtube.com/video/<ID>/edit, подождать ~8 с, JPG 1280x720 взять с raw.githubusercontent.com/MilaWagner/PiLady/tmp-cov-nov4/cov/<имя>.jpg
  (положить туда и запушить), поставить в `#file-loader` через DataTransfer + change, ~6 с, нажать `#save` если активен, ~9 с. #save неактивен = сохранено.
  ID чувствительны к регистру.
- Временные ветки tmp-* на GitHub Людмила удаляет сама.
